# Ware Dental Care — Local Sites Lab concept

Concept Next.js website for **Ware Dental Care** (3 West Street, Ware, Hertfordshire SG12 9EE). Not the live or official site.

- **Layout:** Under One Roof Care Hub (multi-disciplinary mosaic — unique vs Epping Treatment Clarity Pathway)
- **Design brief:** [research/DESIGN_BRIEF.md](research/DESIGN_BRIEF.md)
- **Source log:** [research/SOURCE_LOG.md](research/SOURCE_LOG.md)
